# 分镜层写作守则（随 chenyu-gate skill 分发）

> 写【画面】【运镜】【转场】层时对照执行。与服务端出片规则同源，
> 剧本层按此写 = 转分镜/优化阶段不打架、意图不丢。

## 连续性硬规则（道具 / 位置姿态 / 载具 / 场景）——转分镜乱的根源在这

剧本源头没交代清楚这四类,下游转分镜会忠实继承模糊、出片就乱。落笔即守:

1. **道具持有权连续**:道具一旦交接(A 把箱子递给 B、B 提起 A 的箱子),后续**每个相关场次的 △ 都要延续持有状态**——他提着就一直提着,不无源倒回原主。
   - 反例(真实事故):SHOT7 董伯文接过徐静兰的箱子(各提一个),SHOT8 徐静兰的箱子又莫名回她手里。
   - 正写:交接后每镜都写清谁手里拿着什么("董伯文两手各提一箱走在前,徐静兰空手跟在侧")。
2. **物理位置/姿态连续**:坐/站、车顶/车内、手提/放下、抱着/背着——**连续动作里一旦确立就沿用**,除非剧本明写反向动作(站起来、下车、放下)。
   - 反例:上一场坐车顶,下一场直接变坐车内,中间没有"从车顶下来钻进车厢"的动作。
3. **载具移动=位移,必须分场景**(校验器会机械查这条):**上车、车行途中、下车是三个不同场景**——不同 `N-M` 场次头、不同地点名。绝不能把上车点和下车点写在同一个场景标题下(否则转分镜做成同一地点)。
   - 正写:`1-1 XX站 …△上车` → `1-2 车厢内 …△车行` → `1-3 YY街口 …△下车`。
4. **载具/建筑进出要有过渡**:上/下车、进/出门,写明进出动作(手扶车门→迈步下车→站定新环境),或单独补一个过渡场次;不能瞬移、不能省掉进出这一步。

> 校验器只能机械抓第 3 条(上下车同场景报警);第 1/2/4 条是语义连续性,靠本节自觉遵守——写每一个 △ 前先想"上一镜他手里拿着什么、坐着还是站着、在哪",据此续写。

## 景别（默认 9:16 竖屏）
- 含人物镜头最宽到**中全景**（膝上至全身，人物占主体）；纯环境空镜不受限。
- 对话/反应优先**半身中景、过肩反打、三分法偏位**；少用面部大特写、正中对称构图。
- 面部急推只留给集尾爆点（见词条预算）。

## 剪辑与转场
- 镜头之间一律**硬切**；严禁叠化、淡入淡出、白闪等转场特效。
- 换地点/明显时空跳跃/重大情绪转折：补 1 个 **≤1.5 秒过渡镜**（新时空的环境空镜
  或标志性局部特写）；同地点只换时段用光线交代，不加空镜。
- 场与场衔接手法：声音先入（J-cut）、动作匹配、图形匹配、同机位同构图呼应。
- 一个 SHOT = 一个视频任务：单镜内部机位不堆砌（≤2-3 拍），多机位拆成独立 SHOT。

## 轴线与朝向
- 双人对话先建立"谁左谁右"，反打/过肩**不越轴**（过肩只换挡谁的肩，不对调左右）。
- 说话镜头三件套：**面向[听话对象] + 视线落在其脸上 + 头部不转向第三者**；
  听话对象保持在画内不被遮挡。通话/画外音场景不适用。
- 听话对象由台词称呼语决定，不由画面站位决定。

## 人数与角色
- action 里 2 个以上同类可数人物，紧前面写**确切人数**（"两个孩子[甲][乙]"）；
  单人镜不写；无身份锚点的人海用约数。
- 单镜『镜头角色』**≤6 个**（建议 4），全景只列需辨认面部者；道具不进镜头角色。

## 打斗
- **一镜一回合**：一次攻防交换一个 SHOT，不把连招塞进单镜。
- 受力反馈**三选二**：受击方位移/表情痛感/环境反馈（撞翻桌椅、扬尘、器物碎裂）。

## 高光词条（每集合计 ≤3 次）
道具前景 / 摇扫锁定 / **急推爆点**（只用于真相揭晓、集尾钩子）/ 穿越前景 /
Snorricam 体感 / 反差剪影；镜头光学性格 3 档（广角贴近 / 标准 / 长焦压缩）。

## 长镜头 [LongTake]
- 每集**至多一次**，12-15 秒高光段；写成**散文惯性链**（动作一气呵成），
  严禁编号节拍或时间戳分段（会导致成片闪烁硬切）。
- 复合运镜三段式仅 OPT-IN 用于高光，不做常规。

## 细节动作
- 进出门四步：手→门把手→门开合→脚步入内。
- 最后一句台词必须在片尾前**含尾音说完**，片尾留约 0.5 秒无台词收尾画面。
- △ 只写可见外部动作；心理一律翻译成身体反应（手指收紧/别开视线/退半步）。
